# Cartilha 01 - Sistema de Gestão de Acesso (SGA)

Documentação técnica e manual prático interativo sobre o Sistema de Gestão de Acesso (SGA), formatado em Markdown para publicação no **Read the Docs** via **MkDocs**.

## 📌 Sobre o Projeto

Este repositório contém a documentação da **Cartilha 01 - SGA**, integrante da *Coleção de Boas Práticas para Melhoria da Experiência do Usuário*, publicada pelo Ministério da Gestão e da Inovação em Serviços Públicos (MGI).

O manual orienta órgãos e entidades públicas, gestores, usuários e a equipe da Central de Atendimento (0800) sobre as diretrizes de adesão ao SGA, cadastro de usuários, solicitação de perfis no SIASG/Compras.gov.br, correção de pendências e padronização do atendimento.
